# [Karakoen](https://operarioribeiro.github.com/Karakoan)

> _"A karaoke for texts reading."_

## Open Project:

**Karakoan**, or **textoke**, is a [public houses (pubs)](https://en.wikipedia.org/wiki/Pub) [sarau](https://en.wikipedia.org/wiki/Sarau_(event)) [lightning talk](https://en.wikipedia.org/wiki/Lightning_talk) methodology inspired by lore recitation and commenting [koans](https://en.wikipedia.org/wiki/Koan).

## Open Methodology:

1. [Curate](https://en.wikipedia.org/wiki/Content_curation) a [text](https://en.wikipedia.org/wiki/Text_processing) like a [poetry](https://en.wikipedia.org/wiki/Poetry), [literature](https://en.wikipedia.org/wiki/Literature), [handbook](https://en.wikipedia.org/wiki/Handbook), [recipe](https://en.wikipedia.org/wiki/Recipe), etc.
2. Disclose to everyone your [place of speech](https://www.uib.no/bnkf/143972/%E2%80%9C-place-speech%E2%80%9D-according-djamila-ribeiro) the [voice](https://en.wikipedia.org/wiki/Voice) [prosody](https://en.wikipedia.org/wiki/Prosody) [tone of communication](https://voiceplace.com/types-tone-voice-communication) you will use whether a [rethorics](https://en.wikipedia.org/wiki/Rhetoric), [declamation](https://en.wikipedia.org/wiki/Declamation), [tragedy](https://en.wikipedia.org/wiki/Tragedy) interpreation, [stand-up comedy](https://en.wikipedia.org/wiki/Stand-up_comedy). 
3. You can open for brief comments and use tools like [Kahoot!](https://kahoot.it) to grade and evaluate presentations.
